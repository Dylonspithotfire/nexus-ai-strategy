# Nexus AI Strategy

> **AI that finds money in your operation. Not hype in your inbox.**

A responsive, mobile-first single-page landing page engineered for **Nexus AI Strategy**, a solo Fractional AI Architect consultancy for mid-sized logistics and supply chain firms ($10M–$50M revenue, 50–200 employees).

---

## 🧭 Brand & Positioning

- **Audience**: Mid-market 3PLs, freight brokerages, regional carriers, wholesale distributors ($10M–$50M revenue, 50–200 employees).
- **Tone**: Boardroom-credible, precise, confident, no fluff.
- **Color System**:
  - Deep Navy: `#10243E`
  - Slate: `#5A6B7F`
  - Paper: `#F6F4EF`
  - Copper Accent: `#C98A2E`

---

## 🛠️ Landing Page Features

1. **Sticky Header & Navigation**: Brand wordmark, smooth-scrolling section links, and "Book the Audit" CTA with mobile drawer menu.
2. **Hero Section**: Pragmatic value proposition with dual CTAs (Audit & Quiz) and a 4-part credibility benchmark strip.
3. **Who This Is For / Isn't For**: Unvarnished boundary definition contrasting mid-market logistics operators against pre-revenue wrapper startups and broken physical operations.
4. **The Problem**: 4 operational friction breakdowns: Carrier Invoice & Accessorial Leakage, "Where's My Load?" Status Email Firefighting, Legacy Stack Isolation (McLeod, TMW, SQL), and the Enterprise Consulting Trap.
5. **Three Transparent Service Cards**:
   - **AI Readiness Audit — $3,500 one-time** (Primary featured engagement with 10-day turnaround).
   - **Agent Implementation — $15,000 per project** (Turnkey production engineering with human-in-the-loop review).
   - **Strategic Retainer — $4,000 / month** (Direct fractional advisory capped at 4 firms).
6. **4-Step Process**: `Audit, Decide, Build, Measure` with milestone timelines and deliverables.
7. **Interactive 5-Question Audit Intake Quiz**: Tailored diagnostic scorecard that **never promises speculative ROI**, featuring an automated transfer button to pre-fill the final contact form.
8. **Operational Capacity & ROI Estimator**: Interactive sliders computing `Hours Saved/Week × Hourly Rate × 52`, explicitly annotated as an estimate derived strictly from user inputs.
9. **About Section**: Profile of Marcus Vance (Fractional AI Architect) explaining why direct principal access eliminates agency overhead.
10. **FAQ Accordion**: 6 comprehensive answers addressing legacy TMS integration, private data containment, pricing, error handling, and timelines.
11. **Final Contact Form & Confirmation**: Validated fields (Name, Company, Work Email, Size Band, Primary Bottleneck, Context) transitioning to an executive confirmation panel.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it with any static HTTP server:

```bash
# Using Python
python3 -m http.server 8080

# Using Node
npx serve .
```
